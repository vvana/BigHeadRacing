# Сервер сетевой игры на VDS

Модель — **выделенный сервер**: на VDS крутится headless-экземпляр самой игры.
Он считает всю гонку (2 слота живых игроков + 2 бота) и рассылает состояние,
клиенты шлют только ввод. Никто из игроков не хостит, поэтому «нулевого пинга
у хозяина» ни у кого нет — условия равные.

Транспорт — ENet поверх **UDP**, порт по умолчанию **9977**.

---

## 1. Что нужно на VDS

- Linux x86-64 (Debian/Ubuntu — в примерах ниже).
- Godot **4.3** headless-сборка для Linux. GUI не нужен, X-сервер тоже.
- Открытый **UDP**-порт 9977 (и в firewall, и в панели провайдера).

```bash
sudo apt update && sudo apt install -y unzip wget
cd /opt
sudo wget https://github.com/godotengine/godot/releases/download/4.3-stable/Godot_v4.3-stable_linux.x86_64.zip
sudo unzip Godot_v4.3-stable_linux.x86_64.zip
sudo mv Godot_v4.3-stable_linux.x86_64 /usr/local/bin/godot
sudo chmod +x /usr/local/bin/godot
godot --version
```

## 2. Положить проект

Скопировать папку проекта целиком (с `project.godot`, `scripts/`, `scenes/`,
`assets/`) в `/opt/bighead`. Например с рабочей машины:

```bash
rsync -av --exclude '.git' --exclude 'tools/shots' ./ user@ВАШ_VDS:/opt/bighead/
```

Один раз импортировать ресурсы (иначе первый запуск будет долгим):

```bash
cd /opt/bighead && godot --headless --path . --import
```

## 3. Открыть порт

```bash
sudo ufw allow 9977/udp
```

Если firewall не ufw, а nftables/iptables или порт закрыт ещё и в панели
хостера — открыть UDP 9977 там же. **Это самая частая причина «сервер не
ответил»:** TCP-порт открыть недостаточно, ENet ходит по UDP.

## 4. Проверить руками

```bash
cd /opt/bighead && godot --headless --path . res://scenes/Main.tscn -- --server
```

В консоли должно появиться:

```
[net] сервер слушает UDP-порт 9977, слотов игроков: 2
[net] трасса готова, ждём игроков
```

Дальше сервер печатает, кто занял какой слот и когда стартовал заезд.

## 5. Автозапуск (systemd)

Скопировать `bighead-server.service` в `/etc/systemd/system/` и:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now bighead-server
sudo systemctl status bighead-server
journalctl -u bighead-server -f
```

## Как играть

1. Запустить игру на двух машинах.
2. На экране выбора машины — поле рядом с кнопкой, там уже вписан адрес
   VDS (139.100.234.166:9977), нажать **ПО СЕТИ**. Свой адрес запоминается
   (`user://net.cfg`).
3. Подключились оба — заезд стартует сразу. Подключился один — сервер ждёт
   второго **5 секунд** и стартует с ботами (пробел — не ждать вовсе).
   Второй игрок может подсесть и позже: он заберёт машину у бота.

В гонке: **своя** машина помечена зелёной стрелкой, **живой соперник** —
оранжевой. Боты без стрелки.

## Что делает сервер сам

- Слот, который никто не занял, ведёт бот. Игрок подключился — машина
  переходит под него, вышел — снова бот, гонка не останавливается.
- Заезд закончился — через 8 секунд трасса перезапускается для следующей пары.
- Все игроки вышли посреди заезда — трасса перезапускается сразу, чтобы
  следующие не догоняли уехавших ботов.

## Порт

Порт зашит в `scripts/Net.gd` (`const PORT := 9977`). Меняете там — не забудьте
firewall и адрес в игре (`адрес:порт` пишется в то же поле).
